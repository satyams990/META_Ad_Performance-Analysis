# 📊 Meta Ad Performance Analysis Dashboard

An end-to-end interactive **Power BI dashboard** designed to analyze
Meta (Facebook & Instagram) advertising performance. The dashboard
provides a complete marketing funnel view---from impressions to
purchases---along with audience, geography, budget, and time-based
insights to support data-driven campaign optimization.

------------------------------------------------------------------------

## 🚀 Project Objective

The objective of this project is to help marketing teams:

-   Track campaign performance across Facebook & Instagram
-   Measure advertising effectiveness using business KPIs
-   Analyze customer engagement and conversion funnel
-   Identify high-performing audiences and ad formats
-   Optimize budget allocation using data-driven insights

------------------------------------------------------------------------

## 📂 Data Model

**Fact Table** - Ad Events

**Dimension Tables** - Ads - Campaigns - Users - Date Table

## 📈 Key KPIs

-   Impressions
-   Clicks
-   Shares
-   Comments
-   Purchases
-   Engagements
-   CTR (Click Through Rate)
-   Engagement Rate
-   Conversion Rate
-   Purchase Rate
-   Total Budget
-   Average Budget per Campaign

------------------------------------------------------------------------

## 📊 Dashboard Features

-   Executive KPI Cards
-   Dynamic KPI Selector
-   Gender-wise Analysis
-   Age Group Analysis
-   Country-wise Performance Map
-   Calendar Heatmap
-   Weekly Trend Analysis
-   Hourly Trend Analysis
-   Ad Type Performance Matrix
-   Interactive Filters & Cross-filtering

------------------------------------------------------------------------

## 💡 Key Insights

-   High awareness and engagement across campaigns.
-   Purchase funnel has scope for optimization.
-   Females aged 18--30 show the highest engagement.
-   Video and Story ads outperform other ad formats.
-   Afternoon and evening campaigns generate maximum engagement.
