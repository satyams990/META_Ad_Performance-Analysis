# 📊 Meta Ad Performance Analysis Dashboard

> An interactive **Power BI** dashboard for analyzing Meta (Facebook &
> Instagram) advertising campaigns through KPI tracking, audience
> segmentation, geographic analysis, and time-based performance
> insights.

------------------------------------------------------------------------

## 🚀 Project Overview

This dashboard helps marketing teams monitor campaign performance,
identify high-performing audience segments, optimize advertising spend,
and improve conversion efficiency using interactive business
intelligence visualizations.

## 📊 Dashboard Features

-   Executive KPI Cards
-   Dynamic KPI Selector
-   Audience Analysis (Gender & Age)
-   Country-wise Performance Map
-   Monthly Calendar Heatmap
-   Weekly Trend Analysis
-   Hourly Trend Analysis
-   Ad Type Performance Matrix
-   Interactive Slicers & Cross-filtering

------------------------------------------------------------------------

## 💡 Business Insights

-   Strong awareness and engagement across campaigns.
-   Female users aged 18--30 show the highest engagement.
-   Video and Story ads deliver the best performance.
-   Afternoon and evening campaigns generate maximum engagement.
-   Conversion funnel has scope for optimization.
